# 验收摘要（V0.1）

本文件摘录本地验收记录中可公开的部分，说明"哪些能力有证据、证据到什么程度"。所有测试均在隔离环境或临时会话中完成，未改动正式学习记录。

## 一、结构可重建

| 章节 | 题量 | 分层（课后 / 执医 / 考研） | 重建结果 |
|---|---|---|---|
| 支气管哮喘 | 167 | 8 / 121 / 38 | 隔离重建产物与正式题库逐字节一致 |
| 肺血栓栓塞症 | 84 | 8 / 59 / 17 | 同上 |

"逐字节一致"指同一份内容源与题库输入下，两次编译输出完全相同，说明编译过程可复现、无隐藏状态。

## 二、服务与门禁

- 服务端回归测试 **10 项通过**，覆盖：章节隔离、作答写入、重复作答保留、旧题号映射、只读加载文件不被改写。
- 两章门禁通过：页面返回 200、章节 API 正常、讲义 PDF 按页可取、未知章节被拒绝、入口文件检查通过。
- 前端脚本与阅读器脚本通过语法检查。

## 三、浏览器行为（隔离会话）

- 从目录进入小节，PDF 正常渲染；
- 作答后刷新页面，作答与理由仍可恢复；
- PTE 旧题号作答恢复：进入练习后分层计数为 1 / 1 / 0 / 0，答题卡显示旧理由；
- 再次作答后计数变为 2 / 2 / 0 / 0，答题卡仍只有一道题"已答"，显示最近理由；
- 原文选区提问与题卡提问均携带正确的小节与页码上下文。

## 四、历史作答兼容

旧版 `tt-pte-1` 与新版本 `tt-pte-01` 不是同一字符串。服务端在读取 PTE 历史作答时做只读映射：

- 旧键、旧理由、旧反馈原样保留；
- 新作答写入当前题号；
- 未做等价替换，避免把两道不同题目误认成同一题。

## 六、证据性质说明

上述结论均来自本地隔离验收，不是公开环境复现结果。公开包不含题库与讲义，无法直接复跑；复现需要完整的本地资料布局。
