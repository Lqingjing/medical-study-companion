# 功能介绍与使用流程

本文件描述 V0.1 的实际行为。界面示意见 `demo/` 目录（原创示意图，非真实截图）。

## 一、整体流程

```
选择章节 → 按小节读原讲义 → 到卡点停下做主动回忆
        → 做本节关联题 → 看反馈并跳回原页 → 记录留在本机
```

## 二、阅读原讲义

1. 打开章节后进入小节列表，每个小节对应讲义的一段页码范围。
2. 阅读区直接渲染原讲义 PDF 页，可翻页、缩放、选中文字。
3. 选中文字后可直接就该句提问，问题会自动带上小节、来源页与选区原文。
4. 阅读位置按章节保存，下次进入可回到上次小节。

设计要点：不把讲义转成 HTML 再排版，避免公式、表格和图注在转换中失真；书页码与 PDF 页序的偏移在内容源里配置。

## 三、主动回忆（R0 / 正式提取）

工具本身不强制节奏，提供三个记录入口：

| 环节 | 记录什么 | 用途 |
|---|---|---|
| 小节卡点 | 能否用自己的话重建本节核心 | 暴露"看懂了但说不出" |
| 单元末正式提取 | 整体结构与节点连接 | 区分首次独立表现与提示后表现 |
| 延迟复测 | 隔天/下次开课前的独立重建 | 判断是否只是短时记忆 |

服务端只记录结果与时间点，不自动判定掌握程度；是否算通过由使用者判断。

## 四、分层做题

1. 题库按三层组织：课后题、执医真题、考研真题。
2. 可按层筛选，也可只看本节关联题（依据题目的 `section` 与 `feedback.targetSection`）。
3. 答题卡显示已答题数、作答次数、正确情况。

## 五、题后反馈

提交后展示：

- 正确答案与选项判定；
- 解析与"题眼"（便于记忆的短句）；
- **对应讲义小节与页码**，一键跳回原页；
- 历史作答（同一题多次作答时保留每条记录）。

跳回原页时会保留阅读器状态与滚动位置，返回后仍停在原处。

## 六、追问

- 从讲义选区提问：自动携带小节、来源页、选区文本；
- 从题卡提问：自动携带章节、小节、题号；
- 回答与请求一并写入本机会话文件，刷新后仍可查看；
- 模型接入由本机已登录的客户端完成，工具本身不保存任何凭据。

## 七、记录与恢复

- 每章一个 JSON 会话文件，包含：当前小节、作答、勾画、追问、阅读位置。
- 刷新或重开页面后自动恢复。
- 旧版题号（如 `tt-pte-1`）在新版题号（`tt-pte-01`）下仍可读回旧理由，旧记录不被改写。
- 未提交的草稿、精确滚动位置、临时展开的列表不持久化。

## 八、入口与构建

- 双击入口启动本机服务并打开浏览器；服务只监听 `127.0.0.1`。
- 新增章节：写内容源 → 加编译函数 → 注册 → 一键构建（编译 + 门禁）。
- 门禁失败不会覆盖已有产物。

## 九、界面示意

- `demo/界面示意-阅读页.svg`：阅读区、小节目录、答疑侧栏的布局与信息层级。
- `demo/界面示意-练习反馈.svg`：题卡、选项、反馈与"跳回讲义页"的关系。

两张图均为概念示意图（非运行截图），用于说明信息结构，不含任何真实题目或讲义内容。
