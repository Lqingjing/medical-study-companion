## 三、公开副本的最小改写清单

为公开发布所做的改动仅限以下四类，不涉及功能逻辑：

1. `compile_units.py`：删除 8 道真实真题，替换为 1 道原创占位示例（字段形状保持一致）。
2. 整份移除 `original_content.py`（内容增强模块）。
3. 品牌名中性化：课程与题库平台名称替换为"主讲老师 / 题库 / 口诀"等通用词，涉及 `app.js`、`index.html`、`launch.py`、`server.py`、`compile_units.py`。
4. `打开学习.cmd`：去掉本机 Python 绝对路径。

改写后语法检查通过（Python `py_compile`、Node `--check`），但**不具备运行条件**。

## 四、已知限制

1. **不可直接运行**：缺少题库、内容源、讲义与 PDF.js，启动会报错。
2. **仅两个章节**：未覆盖仅 PPT、无导图、无题库等形态。
3. **计数刷新**：提交后分层标签需刷新或重进练习才更新。
4. **未验证真实学习者体验**：路径是否好找、讲义是否好读、是否形成记忆，仍需本人试用。
5. **旧题号映射仅 PTE**：其他章节若出现题号变更，需要同样的显式映射。
6. **无跨设备同步**：会话保存在本机。
7. **无权限系统**：服务仅监听回环地址，按单用户设计。

- 公开包中的占位示例为原创，不代表任何真实题目。
